# Material role map

`quickshell/core/Theme.qml` exposes the 46 canonical Material roles loaded from `$XDG_STATE_HOME/wizarch/theme/active.json` (or `quickshell/core/Fallback.js` when uninitialized), plus internal compatibility aliases (`textPrimary`, `textSecondary`, `textOnPrimaryContainer`, `divider`, `background`, `onBackground`, `surfaceVariant`, `hoverSurface`, `hoverActiveSurface`).

On-roles (`onPrimary`, `onSurface`, etc.) are exposed as `readonly property alias` bindings to an internal `QtObject` so QML does not misinterpret `on*` property bindings as signal handlers.

## 46 canonical roles

- **Primary**: `primary`, `onPrimary`, `primaryContainer`, `onPrimaryContainer`, `inversePrimary`, `primaryFixed`, `primaryFixedDim`, `onPrimaryFixed`, `onPrimaryFixedVariant`
- **Secondary**: `secondary`, `onSecondary`, `secondaryContainer`, `onSecondaryContainer`, `secondaryFixed`, `secondaryFixedDim`, `onSecondaryFixed`, `onSecondaryFixedVariant`
- **Tertiary**: `tertiary`, `onTertiary`, `tertiaryContainer`, `onTertiaryContainer`, `tertiaryFixed`, `tertiaryFixedDim`, `onTertiaryFixed`, `onTertiaryFixedVariant`
- **Error**: `error`, `onError`, `errorContainer`, `onErrorContainer`
- **Surfaces**: `surface`, `onSurface`, `onSurfaceVariant`, `surfaceDim`, `surfaceBright`, `surfaceContainerLowest`, `surfaceContainerLow`, `surfaceContainer`, `surfaceContainerHigh`, `surfaceContainerHighest`, `inverseSurface`, `inverseOnSurface`
- **Outline & effects**: `outline`, `outlineVariant`, `shadow`, `scrim`, `surfaceTint`

## Component mapping

| Surface / component | Surfaces & accents | Ink, state & boundaries |
| --- | --- | --- |
| `Pill`, `ScreenBorder`, `ScrollingFrameGuard` | `surface`, `ThemeLogo` (`primary`) | `onSurface`, `onSurfaceVariant`, active workspace/status highlights via `primary` |
| `OverlayShadow` | Soft drop-shadow behind panel (`#000000` on light surfaces, `#ffffff` on dark) | Derived from `surface` luminance; intentional halo effect exception |
| `LauncherView`, `LauncherIcon`, `LauncherDragOverlay` | `surfaceContainer`, `surfaceContainerHigh`, `surfaceContainerHighest`, `hoverSurface` | `onSurface`, `onSurfaceVariant`, selection/focus `primary` & `primaryContainer`/`onPrimaryContainer` |
| `CalendarView`, `CalendarDay`, `CalendarMonthCard` | `surface`, `surfaceContainerHigh`, `primaryContainer` (today/selection) | `onSurface`, `onSurfaceVariant`, `onPrimaryContainer`, weekly day off `error`, local event dots (optional event hex color or theme ink), neighbor-month dim (`0.25` / rolling fade) |
| `ControlTile`, `QuickSettings`, `QuickActionCard`, `QuickSliderRow` | Active `secondaryContainer`, idle `surfaceContainerHigh`/`surfaceContainer`, track `primary` | Active ink `onSecondaryContainer`, idle `onSurface`/`onSurfaceVariant`, disabled tile/control opacity (`0.55` / `0.45`) |
| `MediaCard` | `surfaceContainer`, `surfaceContainerHigh` with scrim over artwork | `onSurface`/`onSurfaceVariant`, progress `primary`, play/pause `tertiaryContainer`/`onTertiaryContainer` |
| `NotificationCenter` | `surfaceContainer`, `surfaceContainerHigh` | `onSurface`/`onSurfaceVariant`, urgent card border & `Urgent ·` indicator in `error` |
| `InputPicker` (clipboard / emoji) | `surfaceContainer`, `surfaceContainerHigh`, selected `primaryContainer` | `onSurface`, `onSurfaceVariant`, `onPrimaryContainer` |
| `QuickWheel` | Disk `surfaceContainerLow`, hub `surfaceContainerHigh`, selected sector `secondaryContainer` | Selected arc `primary`, selected icon `onSecondaryContainer`, idle icons `onSurface` |
| `SettingsWindow`, `SettingsView`, `Settings*` | `surfaceContainerLow` window, `surfaceContainer` sidebar/sections, `surfaceContainerHighest` active nav/fields | `onSurface`/`onSurfaceVariant`, focus `primary`, switch track `primary` / thumb `onPrimary`, error banners `error` |
| `ThemedToolTip` | `inverseSurface` | `inverseOnSurface` |
| `ThemedScrollBar`, `FadedDivider` | `outline`, `outlineVariant` | State compositing via `Theme.stateColor(...)` |
| Hyprland borders (`wizarch-theme.lua`) | Active border `primary`, inactive border `outlineVariant` | Strict hex colors generated by `activation.py` |

## State compositing and contrast

`Theme.stateColor(base, ink, hovered, pressed, focused)` composites sRGB overlays with standard maxima of `0.08` (hover), `0.10` (focus), and `0.10` (pressed), reducing opacity in `0.01` steps if needed so enabled ink contrast against the composited surface stays `>= 4.5:1`. Palette validation in `color.py` enforces `>= 4.5:1` for enabled text/on-role pairs and `>= 3.0:1` for interactive focus/primary accents.
